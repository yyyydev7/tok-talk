# 문서 적재 파이프라인

NIOSH 문서 수집·정제·청킹·임베딩·FAISS 생성을 구현할 위치입니다. 현재 실행 스크립트는 없습니다. API 서버 시작 과정에서 문서를 수집하거나 임베딩하지 않습니다.

구현 순서는 다음과 같습니다.

1. 프로젝트 루트의 `datapipeline/data/`에 있는 물질 카탈로그와 출처표를 입력 기준으로 확정합니다.
2. 공식 원문과 확인 시각을 저장하고, 물질별로 본문을 정제합니다.
3. 청크에 `material_id`, CAS, 원문 URL, 문서 항목, `checked_at`을 보존합니다.
4. 임베딩 모델·차원·청킹 규칙·생성 명령·원문 해시를 명세에 기록합니다.
5. 물질별 인덱스를 생성하고, 평가를 거쳐 버전이 있는 산출물로 전달합니다.

`rag/` API 서버는 검증된 인덱스를 읽기 전용으로 사용해야 합니다. 원문 캐시, 임베딩, 인덱스 파일은 Git에 직접 추가하지 말고 팀의 산출물 저장 위치를 정한 뒤 전달합니다. 외부 API 키는 환경변수로 받습니다.
