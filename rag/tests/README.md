# RAG 서비스 검사

업무 기능을 구현할 때 해당 동작을 검증하는 테스트를 이 폴더에 추가합니다. 현재는 업무 기능이 없어 자동 테스트 코드를 두지 않았습니다.

우선 검증할 대상은 JWT 검증 실패, 물질 확정과 검색 범위 제한, 근거 부족 처리, 재고 DB 장애와 RAG 동작 분리입니다. 외부 LLM을 호출하지 않는 검사를 기본 CI에 포함하고, 실제 모델 평가는 별도 평가셋과 실행 결과로 관리합니다. 서비스 간 통합 검사는 [`../../backend/tests/e2e/`](../../backend/tests/e2e/)에서 관리합니다.
