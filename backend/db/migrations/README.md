# DB 마이그레이션

`001_create_auth_users.sql`에 인증 계정 테이블이 정의되어 있습니다. 현재 인증 서버는 개발 환경의
초기 구동을 위해 같은 스키마를 멱등하게 확인·생성합니다.

- API 담당자가 users, inventory_items 등의 스키마를 계약과 함께 확정합니다.
- 변경 SQL은 001_이름.sql 형식으로 추가하고 적용 이력을 관리합니다.
- 이미 적용한 파일은 수정하지 않고 새 변경 파일을 추가합니다.
- 초기화·마이그레이션은 서버 기동과 분리된 배포 작업으로 한 번씩 실행합니다.
- Java는 사용자 테이블, FastAPI는 재고 SELECT 권한을 갖도록 계정을 분리합니다.

이 폴더의 SQL은 현재 Compose가 자동 실행하지 않습니다. 운영 배포 전에는 애플리케이션 계정의
DDL 권한을 제거하고 별도 마이그레이션 실행기로 깨끗한 DB와 기존 DB 양쪽을 검증하세요.
